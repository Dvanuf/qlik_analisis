## Сделано в 0.20.0

### Правила (этап 2 каталога v2)
- **R022 «Связь многие ко многим»** — общий ключ неуникален в обеих таблицах
  (метаданные rows/distinct); мосты — через исключения `R022.tables`.
- **R023 «Мера и поле с одним именем»** — мастер-элемент × поле после NFC;
  без перечня мастер-элементов — пропуск с объяснением.
- **R024 «Отсутствует расширение»** — тип объекта не штатный и не в перечне
  `getExtensionList()`; перенос между средами показывает сломанные объекты.
- **R007** — не флагает ключи, используемые как измерение/мера, + `R007.fields`.
- **R001** — не флагает поля, чьи имена найдены в полном JSON свойств
  (`getProperties`): условия показа/расчёта, действия кнопок, закладки,
  свойства расширений. Убрано упоминание квоты Qlik Cloud.

### UX
- **Меню вкладок в левый сайдбар** (группы ОБЗОР/РАБОТА/ПОМОЩЬ/НАСТРОЙКИ,
  роли tablist, на узком окне — горизонтальная строка).
- **Версия анализатора в шапке** (бейдж + тултип Electron/Node).
- **«Лист» в местах паттерна** — где именно живёт объект.
- **Каталог правил в Excel из UI** (вкладка «Правила»).
- Лимит высоты списка находок в «Скрипте загрузки».

### Инфраструктура
- `npm run rules:export` — каталог правил в Excel.
- `.gitlab-ci.yml` + `npm run ci:checkscript -- файл.qvs` — офлайн-проверка
  .qvs в merge request (код 1 при ошибках; тихий режим — `silent:checkscript`).

## Отложено (требует внешних ресурсов или живого сервера)

| Пункт | Причина отложения |
|---|---|
| X001 замер времени расчёта объекта | Нужны живые сессии Engine и проверка нагрузки на сервер; порог 3 с не откалиброван |
| L013 расхождение с GitLab | Интеграция с GitLab API: нужен доступ к репозиторию и токен; хеш-модуль готов сделать быстро при наличии доступа |
| Снимки свойств (схема QSDA Collection) | Крупный объём; имеет смысл после L013 и CI |
| Оценка экономии памяти у R001 | Источник размеров поля (байты) не проверен на живой версии Engine — без него оценка была бы фикцией |
| Полная виртуализация списков | Заменено лимитом высоты; виртуализация — только при подтверждённых тормозах |
| Полная доступность (aria/клавиатура/focus-trap) | Частично сделано (tablist-роли); остальное — при следующем UX-проходе |
| Унификация стилей + чистка мёртвого CSS | Косметика; делать вместе со следующим визуальным изменением |
