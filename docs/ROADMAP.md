Пункты отложены при ревизии 0.19.0 (полная таблица — в RULES-V2.md).

| M006 → новое правило «Связь многие-ко-многим» | Средний | Расширить `src/extract/associations.js` (уже различает 1:1): уникальность ключа в обеих таблицах; мосты — исключения |

| X001 → замер времени расчёта объекта | Крупный | Сессии Engine, порог 3 с (стартовый), разбор объекта на меры/измерения |
| L013 → расхождение приложения и GitLab | Крупный | Хеш нормализованного скрипта vs файл в репозитории; нужна интеграция с GitLab API |
| Снимки свойств (схема QSDA Collection) | Крупный | Двухшаговый анализ: снимок JSON → правила над снимком; воспроизводимость |
| Экономия памяти рядом с U001 | Небольшой | Оценка по метаданным размеров поля/таблицы |

## Как запускаем (по команде)

1. Выбираем пункты из бэклога (или весь раздел целиком).
2. Я оцениваю объём и порядок, при развилках — вопрос с вариантами.
3. Реализация: правки + тесты + `npm test` + typecheck/build/smoke.
4. Релиз по AGENTS §9: CHANGELOG → release README → STATE → коммит → тег →
   push → GitHub Release с артефактами (без копий на рабочий стол).
5. В ROADMAP: выполненное переносится в CHANGELOG (ссылка на версию),
   пункт из бэклога удаляется.
