# Аудит качества qlik-analyzer — 20.11.2026

**Метод:** 3 независимых ревью-прохода по коду (дубли показателей/функций, навигация
и IA, качество кода renderer/main) + живая интерактивная проверка всех 11 вкладок
в запущенном приложении (0.29.5, dev-сборка) + воспроизведение данных на живом
приложении хаба. Базовый прогон: тесты 553/553.

**Итог: ~120 находок. Критичных — 7, средних — ~35, мелких — остальное.**
Ниже — группировка с приоритетами. Краткий ключ: [P0] чинить немедленно,
[P1] в ближайший релиз, [P2] планово, [P3] косметика.
