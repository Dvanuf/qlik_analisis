# Каталог правил v2 → qlik-analyzer: что принято, что отложено

Сверка внешнего каталога «Правила анализатора Qlik: версия 2» (файл
`qlik-analyzer-rules-v2.xlsx`, 6 листов, 44 правила) с фактическим кодом
анализатора. Решения согласованы: **ID правил сохраняются**, вместо удаления
16 «шумных» правил — **выключение по умолчанию**.

## Решения по схеме v2

| Предложение v2 | Решение | Причина |
|---|---|---|
| Переименовать 59 → 44 (L/M/U/E/F/X) | Отклонено | Ломает rules.json (ключ = ID), вкладку «Правила», домены/области, 40+ тестов, историю прогонов |
| Убрать 16 правил | Выключены по умолчанию | Обратимо; включается галочкой в «Правилах»; история не ссылается на несуществующие правила |
| Q002 слить в E001 (qError) | Отклонено | Статический Q002 — единственная проверка в офлайне (.qvs/.qvw) и QlikView, где Engine недоступен |

## Выключены по умолчанию (16) — `DEFAULT_DISABLED_RULES`

Q006, Q007, R009, R011, R012, R013, R016, R018, R020, R021, S002, S004, S006, S011, S012, S017.
Явный список `disabled` в rules.json заменяет дефолт целиком (пустой список = все включены).
Пресет «Стандартный» во вкладке «Правила» = этот дефолт; «Строгий» = всё включено.
