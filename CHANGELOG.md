под контролем git: каждый релиз помечается тегом `v<версия>`, поэтому любую версию
можно пересобрать из исходников (`git checkout v0.1.5 && npm run build`).

## Как читать эту таблицу

Артефакты версий 0.1.0–0.1.4 физически удалены: я пересобирал `release/` и подчищал старые сборки, прежде чем вы просили сохранять все версии. Исходники тех состояний не зафиксированы в git (репозиторий появился только на 0.1.5), поэтому **воспроизвести их точно нельзя** — только начиная с 0.1.5 каждая версия хранится полностью (исходники + тег + артефакты).

## Правило сохранения

1. Сборка никогда не удаляет предыдущие артефакты — все версии лежат в `desktop/release/`.
2. Каждый релиз: правка `version` в `desktop/package.json`, коммит, тег `v<версия>`.
3. `desktop/release/README.md` — список всех собранных версий с размерами.
4. На рабочий стол копируется **последняя** версия; остальные хранятся в проекте.

## Команды выпуска версии

```bash
cd desktop
npm pkg set version=0.1.6
npm run build
npx electron-builder --win --x64 --config.win.target=nsis
npx electron-builder --mac dmg
cd .. && git add -A && git commit -m "release: v0.1.6" && git tag v0.1.6
```
